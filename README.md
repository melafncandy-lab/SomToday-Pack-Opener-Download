# 📦 Somtoday Pack Opener

Een handige browser extension waarmee je de **Somtoday Pack Opener** kunt gebruiken! 🎉

## ⬇️ Download

Je kunt de **Somtoday Pack Opener Extension** direct downloaden via de onderstaande link:

👉 [**📦 Download Somtoday Pack Opener (.zip)**](./somtoday-packs-extension.zip)

## 🛠️ Installeren

1. Download de ZIP via de link hierboven.
2. Pak het ZIP-bestand uit.
3. Open je browser en ga naar de pagina voor extensies.
4. Zet **Developer Mode / Ontwikkelaarsmodus** aan.
5. Kies **Load unpacked / Uitgepakte extensie laden**.
6. Selecteer de uitgepakte map van de Somtoday Pack Opener.
7. Klaar! 🚀

## ✨ Features

* 📦 Somtoday Pack Opener
* ⚡ Snel en eenvoudig
* 🌐 Werkt als browser extension
* 🔄 Regelmatig updates
